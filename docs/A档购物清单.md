## 二、为什么不买 OLED（和之前说的 A 档不同）

小智有两个面包板变体：`bread-compact-wifi`（I2C 单色 OLED 128x32/64）和
`bread-compact-wifi-lcd`（SPI **彩色** ST7789 240x320）。**预编译固件两个都有**。

我们选彩屏，理由只有一条：**单色 OLED 显示不了表情包**（表情是彩色图/GIF），
而"能不能把我们的脸/表情放上去"正是这条路线要验证的事。差价才 ¥20-30，
OLED 买回来是必扔的。

## 三、接线表（照着接，引脚来自仓库的 config.h）

**INMP441 麦克风**

| 模块脚 | 接到 ESP32-S3 |
|---|---|
| WS | GPIO **4** |
| SCK / BCLK | GPIO **5** |
| SD / DIN | GPIO **6** |
| L/R | GND（选左声道） |
| VDD | **3V3**（只能 3.3V，别接 5V） |
| GND | GND |

**MAX98357A 功放**

| 模块脚 | 接到 ESP32-S3 |
|---|---|
| BCLK | GPIO **15** |
| LRC / LRCLK | GPIO **16** |
| DIN | GPIO **7** |
| SD | 3V3（常开，不接会静音） |
| VIN | 5V（或 3V3 也行） |
| GND | GND |
| 喇叭 +/- | 接喇叭两根线 |

**ST7789 彩屏**

| 屏脚 | 接到 ESP32-S3 |
|---|---|
| CS | GPIO **41** |
| RST / RES | GPIO **45** |
| DC / RS | GPIO **40** |
| SDA / MOSI | GPIO **47** |
| SCL / CLK | GPIO **21** |
| BLK / BL（背光） | GPIO **42** |
| VCC | 3V3 |
| GND | GND |

> 板载 BOOT 键（GPIO0）用来进配网/复位，不用自己接。

## 四、到货后按这个顺序验（每步只验一件事）

1. **刷固件**：下 `v2.5.0_bread-compact-wifi-lcd.zip`（放本地，别用在线烧录，
   省得以后换了服务端地址还要重新配），用 Flash Download Tool 或官方网页工具刷。
2. **配网**：板子起热点 → 手机连上 → 填家里 WiFi。喊 **"你好小智"**，
   先用它官方云（xiaozhi.me）确认**硬件没问题**。
3. **接到我们自己**：配网页把服务端地址改成我们的 Python。**这一步才是真验证**，
   我没写过，得新写一个「小智设备协议」的服务端适配层（协议文档见小智仓库
   `docs/websocket_zh.md`）。

## 五、不买（这次）

- **舵机 / 壳** → C 档的事，协议通了再买。
- **电池 + 充电板** → 常驻场景插电，电池反而是故障源。
- **摄像头模块** → 眼睛跟随留在 PC 上跑（BlazeFace 板子跑不动）。
- **N100** → 身体没通之前都是空谈。

## 六、本轮核实到的三条好消息（都影响后面怎么做）

1. **唤醒词能改成"小柚子"** —— 小智支持 ESP32-S3 上的**自定义唤醒词**（MultiNet，
   拼音输入，模板 `mn6_cn`/`mn7_cn`）。我们 PC 端 KWS 的词就是「小柚子」，
   设备端可以用拼音 `xiao you zi` 试着对上，两边就统一了。
   **注意**：这条只支持 S3/P4，C3 不行 —— 又一个必须买 S3 的理由。
2. **表情 21 个位置，我们的 5 个情绪正好是它的子集** —— 它的表情集合是
   `neutral / happy / laughing / funny / sad / angry / crying / loving / embarrassed /
   surprised / shocked / thinking / winking / cool / relaxed / delicious / kissy /
   confident / sleepy / silly / confused`，我们 `llm/emotion.py` 的
   `happy / sad / angry / surprised / neutral` **全部命中**，映射表是白给的。
   而且支持 **GIF 动图 + 透明 PNG**（尺寸不超过屏幕分辨率，必须给一张 neutral）。
3. **有官方在线工具把我们的图打成 `assets.bin`** ——
   [`78/xiaozhi-assets-generator`](https://github.com/78/xiaozhi-assets-generator)
   是个单页应用，**纯浏览器本地生成、无需后端**，一次能打包：表情包 + 唤醒词 +
   字体（普惠体 14/16/20/30px）+ 聊天背景（浅色/深色）。这就是「丙」路线的
   具体落地方式 —— 我们的设计导成设备端资源，不用写 C++。
