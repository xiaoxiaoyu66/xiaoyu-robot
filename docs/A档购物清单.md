## 二、为什么不买 OLED（和之前说的 A 档不同）

小智有两个面包板变体：`bread-compact-wifi`（I2C 单色 OLED 128x32/64）和
`bread-compact-wifi-lcd`（SPI **彩色** ST7789 240x320）。**预编译固件两个都有**。

我们选彩屏，理由只有一条：**单色 OLED 显示不了表情包**（表情是彩色图/GIF），
而"能不能把我们的脸/表情放上去"正是这条路线要验证的事。差价才 ¥20-30，
OLED 买回来是必扔的。

## 三、接线表（照着接，引脚来自仓库的 config.h）

**INMP441 麦克风**

| 模块脚 | 接到 ESP32-S3 |
|---|---|
| WS | GPIO **4** |
| SCK / BCLK | GPIO **5** |
| SD / DIN | GPIO **6** |
| L/R | GND（选左声道） |
| VDD | **3V3**（只能 3.3V，别接 5V） |
| GND | GND |

**MAX98357A 功放**

| 模块脚 | 接到 ESP32-S3 |
|---|---|
| BCLK | GPIO **15** |
| LRC / LRCLK | GPIO **16** |
| DIN | GPIO **7** |
| SD | 3V3（常开，不接会静音） |
| VIN | 5V（或 3V3 也行） |
| GND | GND |
| 喇叭 +/- | 接喇叭两根线 |

**ST7789 彩屏**

| 屏脚 | 接到 ESP32-S3 |
|---|---|
| CS | GPIO **41** |
| RST / RES | GPIO **45** |
| DC / RS | GPIO **40** |
| SDA / MOSI | GPIO **47** |
| SCL / CLK | GPIO **21** |
| BLK / BL（背光） | GPIO **42** |
| VCC | 3V3 |
| GND | GND |

> 板载 BOOT 键（GPIO0）用来进配网/复位，不用自己接。

## 四、到货后按这个顺序验（每步只验一件事）

1. **刷固件**：下 `v2.5.0_bread-compact-wifi-lcd.zip`（放本地，别用在线烧录，
   省得以后换了服务端地址还要重新配），用 Flash Download Tool 或官方网页工具刷。
2. **配网**：板子起热点 → 手机连上 → 填家里 WiFi。喊 **"你好小智"**，
   先用它官方云（xiaozhi.me）确认**硬件没问题**。
3. **接到我们自己**：配网页把服务端地址改成我们的 Python。**这一步才是真验证**，
   我没写过，得新写一个「小智设备协议」的服务端适配层（协议文档见小智仓库
   `docs/websocket_zh.md`）。

## 五、不买（这次）

- **舵机 / 壳** → C 档的事，协议通了再买。
- **电池 + 充电板** → 常驻场景插电，电池反而是故障源。
- **摄像头模块** → 眼睛跟随留在 PC 上跑（BlazeFace 板子跑不动）。
- **N100** → 身体没通之前都是空谈。

## 六、本轮核实到的三条好消息（都影响后面怎么做）

1. **唤醒词能改成"小柚子"** —— 小智支持 ESP32-S3 上的**自定义唤醒词**（MultiNet，
   拼音输入，模板 `mn6_cn`/`mn7_cn`）。我们 PC 端 KWS 的词就是「小柚子」，
   设备端可以用拼音 `xiao you zi` 试着对上，两边就统一了。
   **注意**：这条只支持 S3/P4，C3 不行 —— 又一个必须买 S3 的理由。
2. **表情 21 个位置，我们的 5 个情绪正好是它的子集** —— 它的表情集合是
   `neutral / happy / laughing / funny / sad / angry / crying / loving / embarrassed /
   surprised / shocked / thinking / winking / cool / relaxed / delicious / kissy /
   confident / sleepy / silly / confused`，我们 `llm/emotion.py` 的
   `happy / sad / angry / surprised / neutral` **全部命中**，映射表是白给的。
   而且支持 **GIF 动图 + 透明 PNG**（尺寸不超过屏幕分辨率，必须给一张 neutral）。
3. **有官方在线工具把我们的图打成 `assets.bin`** ——
   [`78/xiaozhi-assets-generator`](https://github.com/78/xiaozhi-assets-generator)
   是个单页应用，**纯浏览器本地生成、无需后端**，一次能打包：表情包 + 唤醒词 +
   字体（普惠体 14/16/20/30px）+ 聊天背景（浅色/深色）。这就是「丙」路线的
   具体落地方式 —— 我们的设计导成设备端资源，不用写 C++。

**开发板为什么退回**：标题写了 N16R8（对），但 **¥12.2 只有正常 N16R8 开发板价格
（¥35-60）的三分之一**，SKU 名又写的是"**PCB 板**" —— 很可能**只是空 PCB（不含
ESP32-S3 模组）**，或者是不带排针/USB 的定制裸板。**必须问客服**：

1. 这一件**含不含 ESP32-S3-WROOM-1-N16R8 模组**（还是只有 PCB 空板）？
2. 模组**是不是 16MB Flash + 8MB 八线(Octal) PSRAM**？
3. 有没有 **USB-C 接口 + 已焊好的排针**（要能插杜邦线、能刷机）？

还是 **FPC 排线座**（那就得配转接板）。是排针就没问题。

**还没买（确认家里有没有）**：Type-C **数据线**（要能传数据）、5V/2A 充电头。

### 复看详情页后的结论（2026-09-19 晚，用户又发了两张详情页截图）

**① 屏：这块不要，换一块。**
商品图里那根橙色**软排线（FPC）**加"标准屏 10PIN **插接口**"说明白了：它是
**FPC 10PIN 插接口**，要插到带对应插座的板上，**杜邦线插不上去**。
（要买也能救：加买一块 `10P FPC 转 2.54 排针` 的转接板 —— 但得先问客服排线
**间距是 0.5 / 1.0 / 1.27mm 哪种**，不同间距的座不能混用。）

**改买**：**带 2.54mm 排针的「模块」**（8 根脚：VCC / GND / CS / RST / DC / SDA / SCL / BLK）。
判据只有一条：**能直接插杜邦线**。

**关键词的关键是「模块」两个字**（2026-09-19 用户搜不到，就是因为搜的"液晶屏"）：
搜"液晶屏"出来的全是**裸屏 + FPC 软排线**；搜"模块"才是带 PCB 引出排针的那种。可以直接粘：

```
2.0寸 ST7789V 240x320 SPI 模块 排针
2.4寸 IPS ST7789 240x320 SPI 模块 8P
ST7789 240*320 全视角 IPS 模块 焊好排针
```

尺寸 2.0" / 2.4" 都行，**但分辨率必须是 240x320、驱动必须是 ST7789** ——
预编译固件只有这一个配置。**1.3" / 1.54" / 1.9" 那种 240x240 的不要**，
分辨率不匹配会显示错位。价格区间 ¥15-30。

**3 秒判据**：商品图里是**小 PCB 板 + 一排金色针/孔** → 对；
是**裸屏 + 橙色软排线** → 不要。

**② 板：¥12.2 那档是空 PCB，要买的是单板 SKU。**
详情页的 SKU 列表把答案摆出来了：`小智专用PCB板 一个`（¥12.2）就是**一块空 PCB**，
要自己焊模组；同页 `已接入AI+成品发货`（¥97.5）是另一档（带喇叭、装好的成品）。
我们要的都不是这两个，而是在列表里挑**单板**：

- 首选：`乐鑫原装芯片 ESP32-S3 N16R8【向下焊】Type-C口`（原装芯片，常驻跑更稳）
- 更省事：`ESP32-S3 N16R8 焊针+面包板+TypeC`（顺带把面包板和数据线一并解决）
- **别选 `【不焊排针】`** —— 没有排针，杜邦线无处可插
- **别买成品那档**：它的板子是店家自己设计的，引脚和上游 `bread-compact-wifi-lcd`
  一不一致商品页没说；刷错配置会让"是新硬件的锅还是代码的锅"分不清

**【向下焊】是给面包板用的**（排针朝下插进面包板），所以我们**得配一块面包板**
（¥5 左右，或直接选带面包板的那档）。
