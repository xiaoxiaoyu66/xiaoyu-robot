## 1. 最终形态与技术选型

### 1.1 目标形态

```
┌─────────────────────────────────────────────────────┐
│  唤醒(常驻) → 录音+VAD断句 → 语音转文字               │
│                                    ↓                │
│              记忆检索(SQLite + 中文向量) → 拼 prompt  │
│                                    ↓                │
│              DeepSeek 流式回答 → 按句切分 → 语音合成  │
│                                    ↓                │
│              扬声器出声  +  旧手机屏幕上的 Live2D 脸   │
└─────────────────────────────────────────────────────┘
```

### 1.2 选型表（每项都说明了为什么）

| 环节 | 选什么 | 为什么不用另一个 |
|---|---|---|
| 大脑（对话） | **DeepSeek API** | 不用本地 Ollama 3b：陪伴机器人的核心价值就是"会聊天"，3b 中文陪聊质量明显差一档，还会占掉语音要用的显存。API 一轮对话约 0.01 元，一个月几块钱 |
| 唤醒词 | **sherpa-onnx KWS（中文模型）** | 不用 openWakeWord：官方明确只支持英文，做"二娃"要自己合成数据训练，新手会卡死。不用 Porcupine：能用（支持中文），但要注册账号拿 Key，免费档限个人非商用 |
| 语音转文字 | **sherpa-onnx + SenseVoice** | 不用 faster-whisper：中文准确率低一档，更吃资源，Windows 上更麻烦 |
| 语音合成 | **edge-tts**（起步）→ 后期 GPT-SoVITS 克隆音色 | 不用 Piper 起步：Piper 的中文音色偏机械。edge-tts 免费、中文很自然、一行装好，缺点是第一次要联网 |
| 记忆 | **SQLite + bge-small-zh-v1.5** | 不推荐 bge-m3：精度更高但模型 2.2GB，CPU 每次检索要 1～2 秒。bge-small-zh 只有约 95MB，毫秒级，桌面陪伴够用 |
| 读文字 | **RapidOCR** | 中文最强轻量方案，CPU 秒出 |
| 认人 | **InsightFace** | 已确认有免编译的 wheel，Windows 能直接装 |
| 扫码 | **OpenCV 的 QRCodeDetector** | 不用 pyzbar：pyzbar 在 Windows 上要额外装 zbar 的 DLL，是新手经典翻车点 |
| 表情脸 | **Vue3 + Live2D，旧手机当屏幕** | 你的 Vue 主场，成本 0 |
| 跑在哪 | **你的笔记本** | 硬件后面再说，见第 2 节 |

> 说明：上一轮我建议用 BGE-M3，这里改成 bge-small-zh-v1.5。原因是你这台机器没有余量，检索速度和体积比那点精度更值钱。

### 1.3 两个必须写进代码的铁律

**铁律 1：半双工。** 它说话的时候要"闭嘴听不见"。否则扬声器的声音会被麦克风听进去，它会自己唤醒自己、自己打断自己。这是这类项目的头号翻车点。
**铁律 2：首句出声 ≤ 2.5 秒。** 不要把整段回答等完再合成，要按句号/问号切分，出一句念一句。做不到这条，体验就是"死的"。

### 3.6 写唤醒词文件

代码里已经内置这个文件（`config\keywords.txt`）。**注意：不能直接写汉字。**

这个唤醒模型的词表是"音素"级的，中文要用「声母 + 带声调韵母」表示：

```
错：  小宇 :2.5 #0.5 @小宇
对：  x iǎo y ǔ :2.5 #0.5 @小宇
```

写汉字会让 sherpa-onnx 在 C++ 层直接报错退出，连 Python 异常都抓不到 ——
这是我实际踩到并修掉的坑，所以别手写拼音。

生成方式：

```powershell
python scripts\make_keywords.py 小宇              # 先看转换结果对不对
python scripts\make_keywords.py 小宇 --write      # 确认后写进 config/keywords.txt
```

格式：`音素序列 :阈值 #增强 @显示名`。阈值调高越不容易误唤醒，一般 2.0 ~ 4.0。

**换唤醒词只改这一个文件，不用重新训练任何模型** —— 这是选 sherpa-onnx 最大的好处。

## 4. 开发路线：七个步骤（S0～S6），每步都是能跑的成品

**每一步都按同一个模板走：目标 → 要学什么 → 写什么 → 验收 → 卡住怎么办。**

### S0 · 音频自检（第 1 次开工，3 小时）

**目标**：确认麦克风录得到、喇叭放得出。这一步看起来傻，但 90% 的人第一周死在音频设备上，不在 AI 上。

**要学**：采样率（我们统一用 16000Hz）、单声道、什么是"帧"。就这三个词。

**写什么**：新建 `step0_audio_check.py`：

```python
import sounddevice as sd
import numpy as np

SR = 16000   # 语音模型的标准采样率
DURATION = 3

print(sd.query_devices())          # 先看看有哪些设备，记住你要用的麦克风编号
sd.default.samplerate = SR
sd.default.channels = 1            # 单声道

print("开始录音 3 秒...")
audio = sd.rec(int(DURATION * SR), samplerate=SR, channels=1, dtype="float32")
sd.wait()
print("播放中...")
sd.play(audio, SR)
sd.wait()
print("完成。听到自己的声音 = 第一步通了。")
```

跑：`python step0_audio_check.py`

**验收**：清楚听到自己刚才说的话。

**卡住怎么办**：
- 没声音 → `sd.query_devices()` 找到正确编号，用 `sd.default.device = (编号, 编号)` 指定
- 报 `PortAudioError` → 关掉其他占用麦克风的软件（微信、腾讯会议、游戏语音）
- 声音是噪音/速度快 → 采样率被系统改成 48000 了，回到"声音设置→设备属性→高级"改成 16000Hz

### S1 · 能听会说（第 2～3 次开工，约 6 小时）

**目标**：按回车 → 你说话 → 它把你的话转成文字 → 念出来。**先不管 AI，这一步只是打通 ASR + TTS。**

**要学**：什么是 VAD（语音断句，就是"判断你说完了没有"）。

**写什么**：`step1_echo.py`，三块逻辑：

```python
# 1) 录音：录到"安静"为止（最简易的 VAD）
def record_until_silence(max_sec=15, silence_sec=0.8, threshold=0.01):
    block = 0.1                       # 每次读 100 毫秒
    frames, silent, total = [], 0.0, 0.0
    with sd.InputStream(samplerate=SR, channels=1, dtype="float32") as stream:
        print("请说话...")
        while total < max_sec:
            chunk, _ = stream.read(int(block * SR))
            frames.append(chunk.copy())
            total += block
            if np.abs(chunk).mean() < threshold:   # 这段是静音
                silent += block
                if silent > silence_sec and total > 0.5:
                    break                          # 连续安静超过 0.8 秒 = 说完了
            else:
                silent = 0.0
    return np.concatenate(frames).flatten()
```

```python
# 2) 语音转文字（SenseVoice，CPU 跑）
import sherpa_onnx
recognizer = sherpa_onnx.OfflineRecognizer.from_sense_voice(
    model="models/sense-voice/model.int8.onnx",
    tokens="models/sense-voice/tokens.txt",
    language="zh", use_itn=True, num_threads=4,
)
s = recognizer.create_stream()
s.accept_waveform(SR, audio)
recognizer.decode_stream(s)
text = s.result.text
print("你说：", text)
```

```python
# 3) 文字转语音（edge-tts）+ 播放
import asyncio, edge_tts, pygame
async def tts(text, path="reply.mp3"):
    await edge_tts.Communicate(text, "zh-CN-XiaoxiaoNeural").save(path)
asyncio.run(tts(text))
pygame.mixer.init(); pygame.mixer.music.load("reply.mp3")
pygame.mixer.music.play()
while pygame.mixer.music.get_busy():
    pygame.time.wait(50)        # 等它念完再继续，这条很重要（对应"铁律 1"）
```

**验收**：你说"今天天气不错"，它用很好听的女声把这句话念出来。

**卡住怎么办**：
- 识别出来是空的 → 你的麦克风音量太小，或者 `threshold` 设太高，把它改成 0.02 试试
- 识别结果乱码/繁体 → `language="zh"` 确认写了
- 播放没声音 → 确认 pygame 装好，或者 mp3 文件生成没生成
- **这一块卡住超过 1 小时**：直接跳过 S1 的录音部分，先用 S2 的键盘输入版本玩起来，回头再修

### S2 · 有脑子（第 4～5 次开工，约 6 小时）

**目标**：接上 DeepSeek，流式回答，按句念出来。

**要学**：SSE 流式是什么（你简历里做过，其实就是"一个字一个字吐"）；system prompt 是干嘛的。

**写什么**：`step2_chat.py`

```python
from openai import OpenAI
import os
client = OpenAI(api_key=os.environ["DEEPSEEK_API_KEY"],
                base_url="https://api.deepseek.com")

SYSTEM = """你是"二娃"，一台放在书桌上的陪伴机器人。
性格：嘴欠但护短，爱拆台，关键时刻很靠谱。
说话要短，一次不超过两句话，像朋友聊天，不要像客服。"""

history = [{"role": "system", "content": SYSTEM}]

def ask(text):
    history.append({"role": "user", "content": text})
    buf, out = "", ""
    for chunk in client.chat.completions.create(
        model="deepseek-chat", messages=history[-20:], stream=True):
        piece = chunk.choices[0].delta.content or ""
        buf += piece; out += piece
        if any(p in buf for p in "。！？\n"):     # 凑够一句就送 TTS
            sentence, buf = buf, ""
            # speak(sentence)   ← 接 S1 的播放函数，出一句念一句
    if buf: pass  # speak(buf)
    history.append({"role": "assistant", "content": out})
    return out
```

**验收**：你问它答，**第一句话出声在 2.5 秒内**（对应"铁律 2"）。

**卡住怎么办**：
- 报 401 → key 没读到，`echo $env:DEEPSEEK_API_KEY` 确认，或者重开终端
- 回答很长很啰嗦 → 改 system prompt，加"一次不超过两句话"
- 要等好几秒才出声 → 你没做分句送 TTS，检查 `if any(p in buf ...)` 那段

### S3 · 唤醒词（第 6～7 次开工，约 6 小时）

**目标**：不用按回车了，喊"二娃"才醒。

**要学**：关键词文件（你已经写好了）、什么算"误唤醒"。

**写什么**：`step3_wake.py`

**别自己手写 KWS 代码**，去 sherpa-onnx 官方仓库的 `python-api-examples/` 里找 `keyword-spotter-from-microphone.py`，复制过来，把模型路径和 `keywords.txt` 换成你的，跑通之后再把 S1/S2 的逻辑接进去。

**验收**：喊三声"二娃"至少中两次；正常聊天、放音乐时不会自己醒。

**卡住怎么办**：
- 喊不醒 → 麦克风离太远；或者把 `keywords_threshold` 从 0.25 降到 0.15
- 老是误唤醒 → 阈值升到 0.35，或者把唤醒词换成更长的（比如"二娃二娃"）
- **顺带把铁律 1 落实**：进入"正在说话"状态时，麦克风数据直接丢弃

### S4 · 性格 + 记忆（第 8～10 次开工，约 9 小时）

**目标**：它记得住事，有稳定的脾气。**这一步才是"陪伴"和"聊天机器人"的分界线。**

**要学**：向量检索（你做过 PGVector，这里是换 SQLite）、余弦相似度。

**写什么**：`step4_memory.py`

- SQLite 三张表：`messages(id, role, content, ts)`、`facts(id, content, ts)`、`vectors(id, embedding)`
- 每轮对话存进 `messages`
- 每轮回答前：把用户这句话用 `bge-small-zh-v1.5` 编码 → 和 `vectors` 算余弦相似度 → 取最相关的 3 条 → 拼进 prompt
- 每 20 轮让模型总结一次"关于主人的事实"，写进 `facts`

```python
from sentence_transformers import SentenceTransformer
model = SentenceTransformer("BAAI/bge-small-zh-v1.5")
```

> 国内下载模型会卡，先设置镜像再跑：
> ```powershell
> $env:HF_ENDPOINT="https://hf-mirror.com"
> ```

**验收**：今天跟它说"我下周三要交简历"，明天问它"我最近有啥事"，它能说出简历这件事。

**卡住怎么办**：
- 下载模型卡住 → 设好 `HF_ENDPOINT` 镜像，或者先用 `pip install fastembed` 走另一条路
- 检索出来的记忆驴唇不对马嘴 → 先别检索，改成"最近 20 轮全塞进 prompt"，效果也不会差太多

### S5 · 有脸（第 11～13 次开工，约 9 小时）

**要学**：WebSocket 推消息。就用你熟的 Vue3。

**卡住怎么办**：

## 5. 学习路线（配合上面的步骤，不多学一个字）

### 5.1 核心原则

**只学"下一次开工马上就要用的东西"。** 不要囤教程、不要先学完 Python 再做项目——那是永远不会开始的经典死法。

每次开工的时间分配：

| 时段 | 干什么 |
|---|---|
| 前 15 分钟 | 看下面"本次要学的"那一行，其他都不看 |
| 中间 2 小时 | 动手写 / 改 / 跑 |
| 最后 45 分钟 | 写 `notes.md`，记录今天卡在哪、怎么解决的 |

### 5.2 分阶段学什么（对着 S0～S6）

| 阶段 | 只学这些 | 去哪学 |
|---|---|---|
| S0 | Python 怎么装、怎么跑一个 .py、什么是函数、什么是 `import` | python.org 官方中文教程，看到"函数"就停 |
| S1 | 采样率 / 单声道 / 帧；什么是 VAD | sherpa-onnx 官方文档只看 **Python API** 和 **SenseVoice** 两页 |
| S2 | HTTP 流式（SSE）是什么；system prompt 怎么写 | DeepSeek 官方文档"对话补全"一页 |
| S3 | 关键词文件格式（你已写过）、阈值是什么意思 | sherpa-onnx 文档的 **KWS** 一页 |
| S4 | 向量、余弦相似度、嵌入是什么意思 | 搜"向量检索 10 分钟入门"，中文的就行 |
| S5 | 只用你已经会的 Vue3 + 一个 WebSocket 库 | 不用学新的 |
| S6 | 无（用现成库） | — |

### 5.3 关于 Python（你是 Java 出身，这块省很多）

你已经会 Java，Python 真正要适应的只有这几件事，**一晚上就能过**：

| Java 里 | Python 里 |
|---|---|
| `List<String> list = new ArrayList<>();` | `list = []` |
| `map.put(k, v)` | `d[k] = v` |
| `for (String s : list)` | `for s in list:` |
| `{}` 包代码块 | 靠**缩进**包代码块（最容易踩，缩进错了就报错） |
| `new Foo()` | `Foo()` |
| 编译期类型检查 | 运行才知道类型，所以**报错很正常，看最后一行** |
| `null` | `None` |
| `String.format("%s", x)` | `f"{x}"` |

再加一个 `async/await`（和 Java 的 CompletableFuture 一个意思，用于语音合成这种等待型任务），够用了。**类、继承、装饰器这些等用到再学。**

### 5.4 遇到看不懂的代码怎么办

这是你最重要的技能，比学语法重要得多：

1. **先跑起来**，别急着读懂
2. 让 AI（就是我）逐行解释，或者只解释你不懂的那几行
3. **问"这行删掉会怎样"**，比问"这行什么意思"学得快十倍
4. 加 `print()` 看中间值，永远有效

> 原则：**AI 可以帮你写代码，但每一行你都要能说出它在干嘛。** 不然出了 bug 你只能干瞪眼。
